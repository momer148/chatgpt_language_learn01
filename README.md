# Study Pulse

Study Pulse is a local-first language study planner for daily vocabulary, grammar, reading, and listening routines.

## Features

- Daily study schedule with completion tracking
- Vocabulary folders with Anki-style spaced repetition flashcards
- Excel/CSV vocabulary import with columns for word, meaning, sentence, folder, topic, and due date
- Grammar drill queue for books such as Grammatik Aktiv
- Reading and listening logs
- Weekly progress view
- Browser notifications while the app is open
- Local backup and restore through JSON export/import
- Responsive Material You-inspired interface

## Run locally

Open `index.html` directly, or run a small local server:

```sh
python3 -m http.server 4174
```

Then open:

```text
http://localhost:4174
```

Data is stored locally in the browser.
